    Right‑click a nodeMore actions (color, collapse, strikethrough, delete, reset position, add URL)
    Add URL…Right-click a node, choose "Add URL…" (or press Ctrl/⌘ + K with a node selected), then type or paste a web address. Repeat to attach more than one link. Nodes with a URL show a small 🔗 marker alongside any photo thumbnails — click it to open the link (or, with several, pick which one). Right-click the 🔗 marker itself to edit an existing link.
    Add note…Right-click a node and choose "Add note…" to attach a longer note — and you can attach more than one. Each note has an optional title field on its first line (Enter jumps from the title into the body) — the picker menus below use it, falling back to a preview of the body text if it's left blank. Nodes with notes show one small note-shaped marker per note, alongside any photo thumbnails. Click a marker to open that note; inside the editor use Alt + arrow keys to page between them, "+ New note" to start another, and 🗑 to delete the one on screen. Right-click any note marker for a quick list of every note on the node, each with its own ✕ to delete without opening the editor.
    Tasks…Right-click a node and choose "Add tasks…" to keep a checklist for it (e.g. today's to-dos). Nodes with tasks show a small ring marker with a fraction like "2/5" — its fill grows as you check tasks off, and a progress bar on the node fills the same way. Click the ⏱ next to any task to start a 1-minute focus timer for it — click "+1m" any time to add more, it keeps running even if you close the modal, chimes when time's up, and counts down right in the browser tab's title alongside the task name (e.g. "⏱ 0:42 · Water the plants") so you can see it from another tab.
    Drag markers to another nodeA node's note icon, link icon (both shown alongside its photo thumbnails), task ring/progress bar, or any individual photo thumbnail can all be dragged onto a different node to move that note, link, checklist, or photo over — hold Alt/⌥ while dropping to copy instead of move. Each note marker drags just that one note. Dragging the "+N" photo badge moves the rest of that node's photos as a batch.
    Add image to noteIn the note editor, click the 🖼 button to pick a photo, or paste (Ctrl/⌘+V) or drag-and-drop an image straight into the note.
    Add photo…Right-click a node and choose "Add photo…" to attach one or more pictures to it (pick multiple files at once, or repeat to add more later). Nodes with photos show a small thumbnail with a count badge — click it to view full-size and step through them. With a node selected, you can also just paste (Ctrl/⌘ + V) an image straight from your clipboard — handy right after taking a screenshot.
    🏷 Tags (sidebar)Opens a browser of every tag you've added to a photo, gathered from across the whole map. Tap a tag to see every photo carrying it, no matter which node it's on — tap a photo there to jump straight to its node (expanding any collapsed branch in the way) and open it full-size.
    Crop / Add text on photoOpen a photo full-size, then use the ⛶ button to crop it, or the "Aa" button to add a text label. Each click on the photo places one label — drag it into place (or drag its small ⠿ handle at the top-left corner, which always moves it even mid-edit, so you never fight with text-caret placement), pick a color, drag the small dot on its corner to resize the text. Click "Aa" again to place another label; click elsewhere on the photo to just finish the current one. "Apply" bakes every label permanently into the photo.
    ⏱ TimerRight-click a node and choose "Add timer…" to keep a running total of time spent on it. Tap "+1m" in the popup each time you spend a minute on it — no countdown, just a manual tally. The total shows right on the node as a small "⏱ 45m"-style badge; tap the badge (or right-click → the timer item again) to add more or reset it. Saved with the map like everything else.
    Root node clockThe map's central node always shows a small live clock below its title: the current time, UTC/US (NY)/UK world clocks, today's Vietnamese weekday and date, and the lunar date — ticking forward on its own, no setup needed.
